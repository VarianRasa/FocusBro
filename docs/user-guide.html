FocusBro User Guide

Complete step-by-step tutorials and best practices to master FocusBro and boost your productivity.

Task Management Tutorial

1 Creating Your First Task

Learn how to create and organize tasks effectively in FocusBro.

  1. Open FocusBro and navigate to the main dashboard
  2. Tap the floating action button (+) at the bottom right
  3. Fill in the task details:
    • Title: Brief, descriptive name
    • Description: Additional details or notes
    • Priority: High, Medium, or Low
    • Category: Work, Personal, Health, or Learning
    • Due Date: Set deadline if needed
  4. Tap "Save" to create the task
📱 Screenshot: Create Task Dialog
Task creation form with all fields visible
Pro Tip: Use descriptive titles and set realistic deadlines. This helps with prioritization and time management.

2 Organizing Tasks by Views

Navigate between different task views to stay organized.

  • Today: Tasks due today and overdue items
  • In Progress: Tasks you're actively working on
  • Completed: Finished tasks for reference
  • Upcoming: Future tasks and scheduled items
📱 Screenshot: Task Views Navigation
Bottom navigation showing different task views

3 Using Filters and Search

Find tasks quickly using filters and search functionality.

  1. Tap the filter icon in the app bar
  2. Select filters:
    • Priority: Filter by High, Medium, Low
    • Category: Filter by Work, Personal, etc.
    • Status: Filter by completion status
  3. Use the search bar to find specific tasks by title or description
Pro Tip: Combine filters for precise task filtering. For example, "High Priority + Work Category" to see urgent work tasks.

Focus Sessions Tutorial

1 Starting Your First Focus Session

Learn how to use the Pomodoro timer for productive work sessions.

  1. Navigate to the Focus Screen from the bottom navigation
  2. Set your session duration:
    • Use preset buttons (15, 25, 45 minutes)
    • Or set custom duration using the slider
  3. Optional: Add background music or ambient sounds
  4. Tap the "Start Focus" button
  5. Work until the timer ends
📱 Screenshot: Focus Screen Interface
Timer, duration controls, and start button
Note: During focus sessions, notifications may be blocked to minimize distractions. This is normal behavior.

2 Customizing Focus Settings

Personalize your focus experience for maximum productivity.

  • Duration Settings: Adjust default session lengths
  • Break Intervals: Set automatic break reminders
  • Sound Settings: Choose ambient sounds or import music
  • Focus Mode: Enable screen dimming and notification blocking
📱 Screenshot: Focus Settings Dialog
Settings panel with customization options

3 Adding Background Music

Enhance your focus with ambient sounds or personal music.

  1. Tap the music icon in the Focus Screen
  2. Choose from built-in ambient sounds:
    • Rain sounds
    • Forest ambience
    • White noise
    • Cafe atmosphere
  3. Or import your own music files
  4. Create playlists for different work types
  5. Adjust volume and set fade-in/out preferences

Smart Notes Tutorial

1 Creating and Organizing Notes

Capture ideas and organize them effectively.

  1. Navigate to the Notes screen
  2. Tap the "+" button to create a new note
  3. Add title and content using the rich text editor
  4. Add tags for categorization (e.g., #work, #ideas, #meeting)
  5. Pin important notes to keep them at the top
  6. Save the note
📱 Screenshot: Note Editor Interface
Rich text editor with formatting options

2 Using Tags and Search

Find and organize notes using tags and search.

  • Adding Tags: Use # symbol followed by tag name
  • Filtering by Tags: Tap on any tag to filter notes
  • Search: Use the search bar to find notes by content
  • Advanced Search: Combine tags and text search
Pro Tip: Develop a consistent tagging system. Use tags like #project-name, #meeting-notes, #ideas for better organization.

Best Practices & Workflows

Work Productivity

  • Start day by reviewing Today tasks
  • Use High priority for urgent items
  • 25-minute focus sessions for deep work
  • Take notes during meetings
  • Review completed tasks weekly

Study Sessions

  • Create tasks for each subject/topic
  • Use 45-minute focus sessions
  • Take notes while studying
  • Tag notes by subject
  • Track study time with analytics

Personal Projects

  • Break projects into smaller tasks
  • Set realistic deadlines
  • Use Personal category
  • Document progress in notes
  • Celebrate completed milestones

Health & Wellness

  • Schedule exercise and meal planning
  • Use Health category for wellness tasks
  • Set reminders for habits
  • Track progress with notes
  • Use gentle focus sessions for meditation

Tips & Tricks

Productivity Tips

  • Time Blocking: Assign specific time slots to tasks
  • Batch Similar Tasks: Group similar activities together
  • Regular Reviews: Weekly review of completed and pending tasks
  • Realistic Estimates: Don't overcommit, set achievable goals
  • Break Large Tasks: Divide big projects into smaller, manageable tasks

App Usage Tips

  • Quick Task Entry: Use voice-to-text for faster task creation
  • Keyboard Shortcuts: Learn gesture shortcuts for common actions
  • Backup Regularly: Export your data periodically
  • Customize Notifications: Set up reminders that work for your schedule
  • Use Widgets: Add FocusBro widgets to your home screen
