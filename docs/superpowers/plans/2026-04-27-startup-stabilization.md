# Startup Stabilization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make FocusBro reach a recoverable startup UI even when local initialization fails, while preserving a repeatable manual verification loop.

**Architecture:** Keep the Provider app structure. Move critical async startup out of `main()` and into `SplashScreen`, expose explicit database reset through `DatabaseHelper` and `AppInitializationService`, and keep non-critical provider failures visible in logs without preventing first screen access.

**Tech Stack:** Flutter, Dart, Provider, SharedPreferences, sqflite, PowerShell checks, Flutter analyzer/tests run manually by the developer.

---

### File Structure

- Modify: `pubspec.yaml`
  - Keeps dependency overrides for the `record` package family until upstream package constraints are aligned.
- Modify: `pubspec.lock`
  - Locks the compatible `record_*` package versions generated by `flutter pub get --offline`.
- Modify: `lib/services/database_helper.dart`
  - Owns SQLite versioning, schema creation, default data insertion, and local database reset.
- Modify: `lib/services/app_initialization_service.dart`
  - Owns app startup orchestration and local recovery entry points.
- Modify: `lib/main.dart`
  - Builds providers and launches UI without awaiting database/provider initialization before `runApp`.
- Modify: `lib/screens/SplashScreen.dart`
  - Runs startup work, displays progress, catches failures, and offers retry/reset actions.
- Modify: `test/models_test.dart`
  - Adds model/static startup schema checks that do not require app launch.
- Modify: `test/widget_test.dart`
  - Keeps a realistic FocusBro smoke test for `MyApp` configuration.

  Future<void> resetLocalDatabase() async {
    final currentDatabase = _database;
    if (currentDatabase != null) {
      await currentDatabase.close();
      _database = null;

    }
  }

### Task 3: Add Startup Recovery To AppInitializationService

**Files:**
- Modify: `lib/services/app_initialization_service.dart`

- [ ] **Step 1: Replace service with recoverable version**

Replace the full file with:

```dart
import 'package:flutter/foundation.dart';
import 'package:shared_preferences/shared_preferences.dart';
import 'database_helper.dart';
import 'migration_service.dart';
import '../repositories/focus_repository.dart';

class AppInitializationService {
  static final AppInitializationService _instance =
      AppInitializationService._internal();
  factory AppInitializationService() => _instance;
  AppInitializationService._internal();

  bool _isInitialized = false;
  bool _isInitializing = false;
  Object? _lastError;

  bool get isInitialized => _isInitialized;
  bool get isInitializing => _isInitializing;
  Object? get lastError => _lastError;

  Future<void> initialize({bool force = false}) async {
    if (_isInitialized && !force) return;
    if (_isInitializing) return;

    _isInitializing = true;
    _lastError = null;

    try {
      if (kDebugMode) {
        print('Initializing FocusBro app...');
      }

      final databaseHelper = DatabaseHelper();
      await databaseHelper.database;

      final migrationService = MigrationService();
      final migrationPerformed =
          await migrationService.performMigrationIfNeeded();

      if (migrationPerformed && kDebugMode) {
        print('Migration completed successfully');
      }

      final focusStatsRepo = FocusStatisticsRepository();
      await focusStatsRepo.initializeIfEmpty();

      _isInitialized = true;

      if (kDebugMode) {
        print('App initialization completed');
      }
    } catch (e) {
      _lastError = e;
      _isInitialized = false;
      if (kDebugMode) {
        print('App initialization failed: $e');
      }
      rethrow;
    } finally {
      _isInitializing = false;
    }
  }

  Future<void> resetLocalDataForRecovery() async {
    if (kDebugMode) {
      print('Resetting local startup data for recovery...');
    }

    final databaseHelper = DatabaseHelper();
    await databaseHelper.resetLocalDatabase();

    final prefs = await SharedPreferences.getInstance();
    await prefs.remove('database_migration_completed');
    await prefs.remove('database_migration_version');

    reset();
  }

  void reset() {
    _isInitialized = false;
    _isInitializing = false;
    _lastError = null;
  }
}
```

- [ ] **Step 4: Add helper methods**

Add these methods below `_initializeAndDetermineInitialRoute()`:

```dart
  Future<void> _runNonCriticalStartupStep(
    String label,
    Future<void> Function() action,
  ) async {
    try {
      await action();
    } catch (e) {
      if (kDebugMode) {
        print('$label failed: $e');
      }
    }
  }

  Future<void> _retryInitialization() async {
    if (_isRecovering) return;
    AppInitializationService().reset();
    await _initializeAndDetermineInitialRoute();
  }

  Future<void> _resetLocalDataAndRetry() async {
    if (_isRecovering) return;

    setState(() {
      _isRecovering = true;
      _loadingText = 'Resetting local data...';
      _initializationError = null;
      _progress = 0.0;
    });

    try {
      await AppInitializationService().resetLocalDataForRecovery();
      await _initializeAndDetermineInitialRoute();
    } catch (e) {
      if (mounted) {
        setState(() {
          _initializationError = e;
          _loadingText = 'Recovery failed';
        });
      }
    } finally {
      if (mounted) {
        setState(() {
          _isRecovering = false;
        });
      }
    }
  }
```
