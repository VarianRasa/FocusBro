Troubleshooting Guide

Solutions for common issues, performance optimization tips, and technical support for FocusBro.

Quick Fixes

Try these common solutions first before diving into specific issues:

Restart the App

Close FocusBro completely and reopen it. This resolves many temporary issues.

Restart Your Device

A device restart can resolve memory issues and system conflicts.

Update the App

Check if a newer version is available and update to get the latest fixes.

Free Up Storage

Ensure you have at least 500MB of free storage space on your device.

Installation Issues

Can't Install APK

If you're unable to install the FocusBro APK file:

Solution Steps:

  1. Enable "Unknown Sources" in Settings > Security
  2. For Android 8+: Go to Settings > Apps > Special Access > Install Unknown Apps
  3. Select your file manager or browser and enable "Allow from this source"
  4. Try installing the APK again
Note: Some devices may show security warnings. This is normal for APK installations outside the Play Store.

Installation Failed

If installation fails with an error message:

Common Causes & Solutions:

  • Insufficient Storage: Free up at least 200MB of space
  • Corrupted Download: Re-download the APK file
  • Incompatible Device: Check system requirements (Android 5.0+)
  • Previous Version: Uninstall old version first
Pro Tip

Download the APK directly to your device instead of transferring from a computer to avoid file corruption.

Performance Issues

App Running Slowly

If FocusBro feels sluggish or unresponsive:

Optimization Steps:

  1. Close other running apps to free up RAM
  2. Restart FocusBro to clear temporary data
  3. Check available storage (need 500MB+ free)
  4. Disable unnecessary animations in device settings
  5. Clear app cache (if available in device settings)

Device Requirements Check:

  • RAM: 2GB minimum, 3GB+ recommended
  • Processor: Quad-core 1.4GHz or better
  • Android Version: 5.0 or newer

High Battery Usage

If FocusBro is draining your battery quickly:

Battery Optimization:

  • Reduce screen brightness during focus sessions
  • Disable background music if not needed
  • Close the app when not in use
  • Check if focus mode is properly ending sessions
  • Update to the latest version for efficiency improvements
Battery Tip

Use the built-in focus mode settings to automatically reduce screen brightness and optimize battery usage during sessions.

Feature-Specific Issues

PDF Files Won't Open

If you can't open PDF files in FocusBro:

Troubleshooting Steps:

  1. Check if the PDF file is corrupted (try opening in another app)
  2. Ensure the file size is under 100MB
  3. Verify you have storage permission enabled
  4. Try copying the PDF to internal storage
  5. Restart the app and try again
Large File Warning: PDFs over 50MB may cause performance issues on older devices.

Background Music Not Working

If background music or ambient sounds aren't playing:

Audio Troubleshooting:

  • Check device volume and media volume settings
  • Ensure audio permissions are granted
  • Try different audio files or built-in sounds
  • Check if other apps are using audio
  • Restart the app and try again

File Format Support:

  • Supported: MP3, AAC, OGG, WAV
  • Not Supported: FLAC, WMA, proprietary formats

Notifications Not Working

If you're not receiving focus session or task reminders:

Notification Setup:

  1. Go to device Settings > Apps > FocusBro > Notifications
  2. Enable all notification categories
  3. Check Do Not Disturb settings
  4. Ensure FocusBro is not in battery optimization
  5. Test notifications within the app
Focus Mode: Notifications may be intentionally blocked during focus sessions. This is normal behavior.

Data & Sync Issues

Tasks Not Syncing Between Screens

If tasks aren't updating across different app screens:

Sync Solutions:

  1. Force close and restart the app
  2. Check if you have sufficient storage space
  3. Ensure you're not running multiple instances
  4. Try creating a new task to test sync
  5. Restart your device if issues persist
Prevention Tip

Always wait for tasks to save completely before switching screens. Look for confirmation messages or loading indicators.

Data Loss or Corruption

If you've lost tasks, notes, or other data:

Recovery Steps:

  1. Check if you have any backup files
  2. Look for auto-backup in app settings
  3. Restart the app to trigger data recovery
  4. Check device storage for corruption issues

Prevention Measures:

  • Enable automatic backups in settings
  • Manually export data regularly
  • Keep sufficient free storage space
  • Avoid force-closing the app during data operations
Important: Always create backups before major app updates or device changes.

Getting Additional Help

When to Seek Help

Contact support if you experience:

  • Persistent crashes or freezing
  • Data loss that can't be recovered
  • Features that completely stop working
  • Security or privacy concerns
  • Issues not covered in this guide

Before Contacting Support:

  1. Try all relevant solutions in this guide
  2. Check the FAQ section
  3. Note your device model and Android version
  4. Record the exact error message (if any)
  5. List the steps that led to the issue

How to Get Help:

  • Use the feedback feature within the app
  • Check our User Guide for detailed instructions
  • Review the FAQ for common questions
