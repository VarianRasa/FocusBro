API Documentation

Developer resources for FocusBro data formats, export/import, and integration possibilities.

Note: FocusBro currently stores data locally. This API documentation covers data formats and export/import capabilities for integration purposes.

Overview

FocusBro provides several ways to access and manipulate your productivity data:

  • Data Export: Export tasks, notes, and settings in JSON format
  • Data Import: Import data from other productivity apps
  • Backup/Restore: Complete app data backup and restoration
  • File Integration: Work with PDF files and media imports
Local Storage: All data is stored locally on your device using SQLite database with encryption. No external API calls are made for data storage.

Data Formats

Task Object

Tasks are stored and exported in the following JSON format:

{
  "id": "uuid-string",
  "title": "Complete project documentation",
  "description": "Write comprehensive API documentation for FocusBro",
  "priority": "high",
  "category": "work",
  "status": "inProgress",
  "dueDate": "2024-12-20T10:00:00Z",
  "estimatedSessions": 3,
  "completedSessions": 1,
  "createdAt": "2024-12-15T09:00:00Z",
  "updatedAt": "2024-12-16T14:30:00Z",
  "tags": ["documentation", "api", "development"]
}

Note Object

Notes are structured as follows:

{
  "id": "uuid-string",
  "title": "Meeting Notes - Project Kickoff",
  "content": "# Meeting Notes\n\n## Attendees\n- John Doe\n- Jane Smith\n\n## Action Items\n- [ ] Create project timeline\n- [ ] Set up development environment",
  "tags": ["meeting", "project", "kickoff"],
  "isPinned": false,
  "createdAt": "2024-12-15T14:00:00Z",
  "updatedAt": "2024-12-15T14:30:00Z"
}

Focus Session Object

{

  "duration": 1500,

  "startTime": "2024-12-15T10:00:00Z",

  "completed": true,
  "musicTrack": "forest-ambience.mp3",

}

Export/Import

Export Data

FocusBro supports exporting data in multiple formats:

EXPORT Settings → Data & Privacy → Export Data

Export all app data including tasks, notes, settings, and session history.

Export Formats:

Format Extension Description
JSON .json Complete data export with full structure
CSV .csv Tasks and sessions in spreadsheet format
TXT .txt Notes in plain text format

Import Data

Import data from other productivity applications:

IMPORT Settings → Data & Privacy → Import Data

Import tasks and notes from supported formats and applications.

Supported Sources:

  • Todoist: JSON export files
  • Any.do: CSV export files
  • Google Tasks: JSON format
  • Apple Notes: Text files
  • Generic CSV: Custom mapping available

Backup/Restore

Create Backup

Complete app backup including database and media files:

{
  "version": "1.0.0",
  "timestamp": "2024-12-15T15:00:00Z",
  "data": {
    "tasks": [...],
    "notes": [...],
    "sessions": [...],
    "settings": {...},
    "media": [...]
  },
  "checksum": "sha256-hash"
}

Restore from Backup

Restore app data from backup file with validation and conflict resolution.

Warning: Restoring from backup will replace all current data. Make sure to create a backup of your current data before proceeding.

Integration Possibilities

File System Integration

FocusBro integrates with your device's file system for:

  • PDF Import: Open PDF files from any file manager
  • Music Import: Import audio files for focus sessions
  • Note Export: Share notes to other apps
  • Backup Storage: Save backups to cloud storage

Intent Handling (Android)

FocusBro supports Android intents for external integration:

<!-- Open PDF in FocusBro -->
<intent-filter>
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <data android:mimeType="application/pdf" />
</intent-filter>

<!-- Share text to create note -->
<intent-filter>
    <action android:name="android.intent.action.SEND" />
    <category android:name="android.intent.category.DEFAULT" />
    <data android:mimeType="text/plain" />
</intent-filter>
