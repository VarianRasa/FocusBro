Getting Started with FocusBro

Learn how to install and set up FocusBro on your Android device to start boosting your productivity.

Installation

1

Download the APK

Download the latest FocusBro APK file from our website or scan the QR code.

Download FocusBro v1.0.0
Size: ~102 MB
2

Enable Unknown Sources

Before installing, you need to allow installation from unknown sources:

  1. Go to Settings > Security
  2. Enable "Unknown Sources" or "Install unknown apps"
  3. Confirm the action when prompted
3

Install the App

Once downloaded, tap on the APK file and follow the installation prompts.

Note: Your device may show a security warning. This is normal for APK installations.

First Setup

1. Welcome Screen

When you first open FocusBro, you'll see a welcome screen introducing the app's main features.

2. Permissions

Grant necessary permissions for optimal functionality:

  • Storage access (for PDF files and notes)
  • Notification access (for focus reminders)
  • Audio access (for background music)

3. Language Selection

Choose your preferred language (English or Indonesian) from the settings.
